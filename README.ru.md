# MeetRec — запись встреч на Mac с локальной транскрибацией

[English](README.md) | **Русский**

**MeetRec** — бесплатное приложение с открытым кодом для строки меню macOS. Оно **записывает
встречи и звонки** — экран, ваш микрофон и звук собеседников — и **делает транскрипт прямо на
Mac** (Parakeet и разбивка по спикерам). Никакой бот не подключается к звонку, ничего не уходит в
облако. А ещё MeetRec снимает **скриншоты с пометками и распознаванием текста**, как Shottr.

Всё началось как лёгкая **замена OBS** (13 МБ, около 40 МБ памяти) для одной задачи: нажать «запись» во встрече Microsoft
Teams, Google Meet, Zoom (в браузере) или в звонке Telegram — без сцен, источников и настроек
кодировщика.

**Русский и английский.** MeetRec говорит на языке системы; другой можно выбрать в Настройки → Запись →
Язык. Переводы на другие языки
приветствуются (`MeetRec/Localizable.xcstrings`).

## Возможности

- **Один клик или ⌃⌥⌘R** — и экран, микрофон и звук системы пишутся в устойчивый к сбоям
  фрагментированный `.mov` (отдельные дорожки плюс общая; около 0,5 ГБ в час при 1440p HEVC).
- **Автоматическая запись встреч**: начинается, когда Microsoft Teams берёт микрофон, и
  заканчивается, когда отпускает; для звонков в браузере и Telegram MeetRec сначала спрашивает;
  правила для вкладок браузера записывают знакомые звонки без вопроса.
- **Состояние записи на виду**: уровни звука обеих сторон, ⚠️ в строке меню, если источник
  замолчал, контроль места на диске, перезапуск после сбоя.
- **Отметки, пауза и главы**: ⭐ отметки становятся главами видео и строками транскрипта; пауза
  как в OBS.
- **Локальная транскрибация** с именами спикеров (Parakeet Ultra на Neural Engine + pyannote,
  ничего не покидает Mac; Whisper на выбор):
  вашу речь MeetRec находит по дорожке микрофона, остальные голоса узнаёт по образцам.
- **Скриншоты** (⇧⌘4) с замороженным экраном, снимки окна на обоях, редактор пометок (стрелки,
  рамки, шаги, размытие, обрезка), распознавание текста (⇧⌘2) и поиск по картинке.
- Запись отдельного окна, выбор монитора с живыми миниатюрами, «остров» записи у выреза экрана,
  зеркало камеры, чтобы проверить себя перед звонком.

## Лёгкий по устройству

Замерено на одном Mac (Apple Silicon, macOS 26) на одной задаче: встроенный экран 2216×1440,
HEVC, 15 к/с, микрофон и звук системы; окно OBS свёрнуто в трей. Память — как в «Мониторинге
системы», процессор — % одного ядра в среднем за 60 с (`scripts/profile.py`, подробности в
[PROFILING.md](PROFILING.md)).

| | MeetRec 0.7.0 | OBS Studio 32.2.2 |
|---|---|---|
| Размер приложения | **13 МБ** | 438 МБ + системное расширение виртуальной камеры |
| Покой: память | **41 МБ** | 193 МБ |
| Покой: процессор | **0,1%** | 7,3% |
| Запись: память | **36–50 МБ** | 339 МБ |
| Запись: процессор | **12%** | 21% |
| Пробуждения в покое | 0,1 в секунду | 1 в секунду (+124 у расширения камеры) |

Между встречами MeetRec ничего не делает: нет превью и отрисовки сцены. Во время записи
неизменившиеся кадры пропускаются, видео кодируется аппаратно; остальной процессор уходит в
основном на кодирование двух звуковых дорожек (AAC) и приём кадров от ScreenCaptureKit. Зеркало
камеры работает в отдельном процессе, и его 200–350 МБ уходят вместе с окном. Транскрибация идёт
после записи с фоновым приоритетом, по одной модели за раз.

## Сравнение с аналогами

MeetRec маленький и делает одно дело от начала до конца: видео встречи, звук обеих сторон и
локальный транскрипт с именами. Если нужно другое — у программ ниже это получается хорошо.

| | MeetRec | OBS Studio | Otter.ai | Granola | MacWhisper |
|---|---|---|---|---|---|
| Записывает экран (видео) | ✅ | ✅ | — | — | — |
| Пишет ваш микрофон и собеседников | ✅ отдельными дорожками | ✅ после настройки | ✅ | ✅ | ✅ |
| Начинает и заканчивает вместе со встречей | ✅ Teams, браузер, Telegram | — | ✅ (бот по календарю) | Спрашивает, останавливается сам | ✅ |
| Подключает бота к звонку | Нет | Нет | Да (OtterPilot) | Нет | Нет |
| Транскрибация | На Mac | — | В облаке | В облаке | На Mac |
| Имена спикеров | ✅ по образцам голоса | — | ✅ | ✅ | ✅ (Pro) |
| AI-сводки | — | — | ✅ | ✅ | ✅ (ваш API-ключ) |
| Скриншоты, пометки, распознавание текста | ✅ | — | — | — | — |
| Цена / код | Бесплатно, MIT | Бесплатно, GPL | Подписка | Подписка | Платно |

По скриншотам: как **Shottr** и **CleanShot X**, MeetRec замораживает экран, снимает область или
окно на обоях и размечает снимок (стрелки, рамки, нумерованные шаги, размытие, обрезка), с
распознаванием текста и поиском по картинке. Снимков с прокруткой, загрузки в облако и пометок на
видео нет — если они нужны, лучше выбрать эти приложения.

## Что нужно

- macOS 15 или новее, Apple Silicon (транскрибация работает на MLX).
- Xcode и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).
- Для транскрибации: [uv](https://docs.astral.sh/uv/) (`brew install uv`) и аккаунт Hugging Face
  (ниже).

## Сборка и установка

```bash
git clone https://github.com/ProteinR/MeetRec.git
cd MeetRec
./scripts/install.sh
```

Скрипт собирает Release, подписывает его, ставит в `~/Applications/MeetRec.app` и запускает. При
первом запуске macOS спросит доступ к записи экрана и микрофону; после разрешения записи экрана
перезапустите MeetRec.

### Подпись (чтобы разрешения не сбрасывались)

Подписанных готовых сборок нет (нет аккаунта Apple Developer). Без постоянной подписи каждая
пересборка для macOS — новое приложение, и разрешения приходится выдавать заново. Чтобы этого не
было, один раз создайте самоподписанный сертификат для подписи кода:

1. Связка ключей → Ассистент сертификации → Создать сертификат…
2. Имя: `MeetRec Local Code Signing`, тип идентификации: «Самоподписанный корневой», тип
   сертификата: «Подпись кода».

`install.sh` найдёт его по этому имени (или укажите другой в `MEETREC_SIGN_IDENTITY`). Без
сертификата приложение подписывается ad-hoc и тоже работает.

Если разрешения «залипли» (выданы, а приложение всё равно просит):

```bash
tccutil reset ScreenCapture com.dmemruk.MeetRec
tccutil reset Microphone com.dmemruk.MeetRec
```

### Настройка транскрибации

1. Примите условия модели
   [pyannote/speaker-diarization-community-1](https://huggingface.co/pyannote/speaker-diarization-community-1)
   на Hugging Face.
2. Один раз войдите в терминале: `uvx --from huggingface_hub hf auth login` (токен сохранится в
   `~/.cache/huggingface`).
3. В MeetRec: Настройки → Запись → Транскрибация → «Скачать модели» (около 2 ГБ, один раз).

Дальше всё работает локально, с фоновым приоритетом.

## Вопросы и ответы

**Работает ли MeetRec с Zoom, Google Meet или созвонами в Slack?** Звонки в браузере (Chrome,
Safari, Arc, Edge, Firefox, Brave и другие) MeetRec замечает и спрашивает, записать ли; правило для
вкладки записывает сайт без вопроса. Приложения Microsoft Teams и Telegram тоже распознаются.
Приложения Zoom, Slack, Webex и FaceTime пока не распознаются, но запись всегда можно начать
вручную (⌃⌥⌘R).

**Уходит ли что-то в облако?** Нет. Запись и транскрибация идут на Mac; в сеть MeetRec выходит
только для разовой загрузки моделей с Hugging Face (и для поиска по картинке, когда вы его
нажимаете).

**На каких Mac работает?** macOS 15 или новее; транскрибации нужен Apple Silicon (MLX). Собирается
и используется только на Apple Silicon.

## Примечания

- Кнопки поиска по картинке используют обычные страницы загрузки сервисов (официальных API нет) и
  могут сломаться, если сайт изменится. По умолчанию включён только Google Lens, остальные
  включаются в настройках.
- Запись других людей там, где вы живёте, может требовать их согласия. MeetRec участников не
  уведомляет.
